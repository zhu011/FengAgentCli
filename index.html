GitHub
💬

智能对话

多轮上下文对话，SSE 流式输出，思考过程可视化，Markdown 渲染与代码高亮；TUI 与 WebUI 双端。

🕸️

对话图与回退重答

每轮「提问→回答」沉淀为节点，可溯源、可分支；/rollback 回退到任意节点重答，旧分支完整保留。

👥

团队协作

本机 ACP Agent（kimi / dsh / claude…）注册为团队成员，聊天流派单，任务七态台账与流式输出。

🗣️

多 Agent 群聊

把多个 Agent 拉进一个团队讨论，你随时插话；聊到可收口时「拍板」一键收敛定格结论。

🧲

插件市场

Settings「市场」页浏览 / 搜索 4000+ 社区策展插件，一键 npm 安装，A/B/C 三档兼容徽标。

🧩

WebUI 插件扩展面

fengagent.webui 协议——插件向前端注册 slot（导航 / 设置 / 会话侧栏），装上即渲染。

⚙️

Settings 热切换

网页里配 Provider / 模型 / API Key，保存即热切换，下一轮对话生效，无需重启宿主。

🔧

工具调用与沙箱

文件读写、Bash、Glob/Grep、Web 抓取、记忆、Skill；实验代码在隔离沙箱执行，安全可控。

📡

观测与调用链

trace 全量落盘，WebUI 四层调用链树（会话→消息→LLM 调用→工具调用）+ 指标图表与模型对比。

🧪

评测与自优化

bun run eval 自动生成工具成功率 / KV Cache 报告；--judge 全链路评测产出可执行调优建议。

🧠

记忆系统

MEMORY.md + 分类记忆 + 向量检索，跨会话记住项目上下文。

📜

事件溯源

会话以 append-only 事件日志为准，可导出 / 导入 / 重建 / 跨机迁移。
